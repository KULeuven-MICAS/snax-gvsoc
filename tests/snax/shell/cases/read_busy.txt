# Busy reads the unit's busy in the read's cycle: 0 before the start, 1 from
# the cycle after the accepted start to the run's last cycle E, 0 after. The
# start in c2 is accepted, busy from c3; the inputs are valid from c5, so the
# run of 2 fires in c5 and c6: E = 6.
fields loopCount
config count
wait lockstep
inputs 2
cycles
# a b out  access   result  busy
0 0 1      r 2      0       0     # 0: never started
0 0 1      w 0 2    1       0     # 1: loopCount 2
0 0 1      w 1 1    2       0     # 2: start accepted; busy from 3
0 0 1      r 2      1       1     # 3: busy, no input
0 0 1      r 2      1       1     # 4
1 1 1      r 2      1       1     # 5: fires
1 1 1      r 2      1       1     # 6: fires, E
1 1 1      r 2      0       0     # 7: idle
