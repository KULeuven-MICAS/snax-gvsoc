# STATUS bit 0 reads the unit's busy in the read's cycle: 0 before the
# start, 1 from the cycle after the accepted start to the run's last cycle E,
# 0 after; then bit 1 (done) is set, so a read after the run gives 2. The
# start in c2 is accepted, busy from c3; the inputs are valid from c5, so the
# run of 2 fires in c5 and c6: E = 6.
cycles
# a b out  access   result  status
0 0 1      r 2      0       0     # 0: never started
0 0 1      w 1 2    1       0     # 1: JOBS 2
0 0 1      w 0 1    2       0     # 2: start accepted; busy from 3
0 0 1      r 2      1       1     # 3: busy, no input
0 0 1      r 2      1       1     # 4
1 1 1      r 2      1       1     # 5: fires
1 1 1      r 2      1       1     # 6: fires, E
1 1 1      r 2      2       2     # 7: idle, done
