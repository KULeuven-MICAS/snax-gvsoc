# A read-write CSR reads back as written, all 32 bits at job_width 32; START
# written with bit 0 clear (6) starts nothing and reads 0, a strobe with no
# register. Writes are taken at once
# (answered in their own cycle); a read gives the register in its cycle. No
# start, so STATUS stays 0.
cycles
# a b out  access          result      status
1 1 1      w 1 0xdeadbeef  0           0     # 0: JOBS, taken at once
1 1 1      r 1             0xdeadbeef  0     # 1: as written
1 1 1      w 0 6           2           0     # 2: START, bit 0 clear: a plain write
1 1 1      r 0             0           0     # 3: START reads 0
