# A start with JOBS 0 after a run: the empty run, accepted and ended by the
# shell in its own cycle without the unit (E = a = 6): busy stays 0, the
# counter is reset to 0, and done, already set by the run before, stays set:
# the empty run's done pulse in c6 wins over the start's clear. c1's start
# (JOBS 2) is busy c2, c3, so the counter reads 2 in c4.
cycles
# a b out  access   result  status
1 1 1      w 1 2    0       0     # 0: JOBS 2
1 1 1      w 0 1    1       0     # 1: start accepted; busy from 2
1 1 1      -        -       1     # 2: fires
1 1 1      -        -       1     # 3: fires, E
1 1 1      r 3      2       2     # 4: [2, 3]; done
1 1 1      w 1 0    5       2     # 5: JOBS 0
1 1 1      w 0 1    6       2     # 6: start accepted: the empty run, done in 6
1 1 1      r 2      2       2     # 7: STATUS: not busy, done
1 1 1      r 3      0       2     # 8: reset in c6, no busy cycle since
