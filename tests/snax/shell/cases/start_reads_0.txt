# START is a strobe (D152): no register, so it reads 0 whatever was written,
# before a run, during it and after. JOBS 2; c2's start (0xffffffff: bit 0
# set) is accepted, busy in c3 and c4 (E = 4); STATUS 2 from c5.
cycles
# a b out  access          result  status
1 1 1      w 1 2           0       0     # 0: JOBS 2
1 1 1      r 0             0       0     # 1: START before any start
1 1 1      w 0 0xffffffff  2       0     # 2: start accepted; busy from 3
1 1 1      r 0             0       1     # 3: fires; START reads 0 while busy
1 1 1      r 0             0       1     # 4: fires, E
1 1 1      r 0             0       2     # 5: and after the run
1 1 1      r 2             2       2     # 6: STATUS: done
